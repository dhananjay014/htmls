Multimodal interaction experts · 2024 revision

Not every pair of modalities interacts the same way.

Sometimes image and text repeat the answer. Sometimes only one carries the clue. Sometimes the answer appears only when their meanings conflict or combine. Multimodal MMoE trains a different expert for each case.

redundancyuniquenesssynergyspecialized expertssoft routing
Name disambiguation

The linked paper’s MMoE means Multimodal Mixtures of Experts. It is not Google’s 2018 Multi-gate Mixture-of-Experts architecture for multi-task recommendation, despite the similar acronym.

The full method in one picture

Redundancy

Both modalities independently support the correct label. Fusion should be robust and avoid double-counting the same evidence.

Uniqueness

Only one modality independently supports the correct label. The model must identify and trust the informative side.

Synergy

Neither modality alone predicts the label; their joint relation supplies the task-relevant information.

The key modeling bet

A monolithic multimodal model applies the same parameters to all three situations. MMoE bets that a model trained only on synergistic examples will learn different interaction features from one trained on redundant examples—and that an input-dependent router can choose among them at test time.

Monolithic model\[\hat y=f(x_{image},x_{text})\]

One parameter set handles every interaction regime.

Multimodal MMoE\[\hat y=\sum_{e\in\{r,u,s\}}w_e(x)f_e(x),\qquad \sum_e w_e=1\]

Three specialized predictors are mixed per example.

Memory hook

Classify how the modalities relate before asking what they jointly predict.

For binary labels, the synergy row often appears as both unimodal models choosing the same wrong class while the multimodal label is the opposite class. The A/B/C notation is conceptual and also covers multi-class tasks.

Three concrete intuitions

Redundancy · confirmation

Image: person laughing.
Text: “That was hilarious.”
Task: humor = yes.

Either side already carries the answer.

Uniqueness · dominant modality

Image: generic product photo.
Text: “Battery died in one hour.”
Task: negative review = yes.

The text carries the decisive evidence.

Synergy · relation creates signal

Image: deep winter snow.
Text: “Happy spring—beautiful blossoms!”
Task: sarcasm = yes.

The contradiction, not either side alone, is the clue.

Connection to partial information decomposition

Information theory can decompose information about \(Y\) into redundant, unique, and synergistic contributions from \(X_1\) and \(X_2\). Exact estimation is difficult for high-dimensional continuous modalities, so the paper uses a prediction-disagreement heuristic as a practical proxy.

Conceptual decomposition, not the paper’s estimator\[I(X_1,X_2;Y)=R+U_1+U_2+S\]
The labels are approximate interaction types.

A unimodal model can be wrong because it is weak, not because the information is absent. The MMoE categorization therefore depends on the quality, calibration, and biases of the models used to produce unimodal predictions.

Why sarcasm and humor expose the issue

Congruent cases are easy.

When words, facial expression, image, and tone all agree, correspondence-focused multimodal pretraining is well matched to the task.

Incongruent cases are diagnostic.

Sarcasm often inverts literal meaning. A model must represent opposition, timing, or context rather than simply align similar features.

Step 2 · Turn intuition into labels

Categorization is a two-error count.

Compare each unimodal prediction with the true multimodal task label. Zero, one, or two disagreements map directly to redundancy, uniqueness, or synergy.

Definitions

x_1, x_2Two input modalities, such as image and text.
y_1=f_1(x_1)Prediction from the first unimodal model.
y_2=f_2(x_2)Prediction from the second unimodal model.
y_mGround-truth multimodal task label used for categorization.
δ(a,b)0 if predictions agree; 1 if they differ.
Δ₁,₂Number of unimodal predictions that disagree with \(y_m\).

Paper’s interaction-based categorization

1
\[\delta(a,b)=\begin{cases}0,&a=b\\1,&a\ne b\end{cases}\]
Define discrepancy.For classification, only agreement or disagreement is counted.
2
\[\Delta_{1,2}=\delta(y_1,y_m)+\delta(y_2,y_m)\]
Count unimodal errors.The score lies in \(\{0,1,2\}\).
3
\[\Delta=0\Rightarrow R,\qquad \Delta=1\Rightarrow U,\qquad \Delta=2\Rightarrow S\]
Assign the bucket.Both right → redundant; one right → unique; neither right → synergistic.

Example calculation

Snow image + “happy spring”\[y_{image}=\text{not sarcastic},\ y_{text}=\text{not sarcastic},\ y_m=\text{sarcastic}\]\[\Delta=1+1=2\Rightarrow\text{synergy}\]
Laughing face + humorous sentence\[y_{image}=y_{text}=y_m=\text{humorous}\]\[\Delta=0+0=0\Rightarrow\text{redundancy}\]

Practical data pipeline

Why confidence filtering matters

If \(|p(\text{Yes})-p(\text{No})|\) is small, the bucket may reflect an uncertain labeler rather than a true interaction. Too much filtering, however, leaves too little training data—especially for rare synergy cases.

Step 3 · Specialize by data distribution

Three copies learn three different habits.

The simplest MMoE uses the same backbone architecture three times. Specialization comes from training each copy only on examples assigned to one interaction regime.

Training objective

Interaction-specific empirical risk\[\theta_e^*=\arg\min_{\theta_e}\frac{1}{|D_e|}\sum_{(x,y)\in D_e}\ell\!\left(f_e(x;\theta_e),y\right),\qquad e\in\{r,u,s\}\]

Each expert minimizes the normal task loss—such as binary cross-entropy for sarcasm—but over a different conditional data distribution \(D_e\).

What each expert should learn

\(f_r\) · redundancy

Confirm agreement, remain robust if one view is noisy, and avoid letting duplicated evidence inflate confidence blindly.

\(f_u\) · uniqueness

Detect which modality is informative for this sample and avoid averaging it away with an unhelpful modality.

\(f_s\) · synergy

Model cross-modal relations—contradiction, timing, complementarity, or higher-order combinations—not visible in either marginal input.

The paper notes that redundancy experts could use late fusion and synergy experts could use expressive higher-order operators. Its main experiments demonstrate the simpler data-specialization recipe.

Cost implication

Parameter storageThree expert copies plus a router can approach three times one fine-tuned model’s storage.
Inference computeSoftly fusing all experts runs all three unless the system adds hard/sparse routing.
Subset imbalanceSynergy examples may be scarce; experts can overfit or collapse without filtering and balancing.
Specialization leakageNoisy categories train experts on the wrong regime, reducing the value of separation.
Step 4 · Choose experts without the label

The router must infer the interaction before the answer.

At training time, the true label helps compute the category. At inference time the true label is unknown, so a separate fusion model predicts soft interaction weights from the input itself.

Why training-time categorization cannot be reused directly

Training category\[e=g(y_1,y_2,\color{#a23f35}{y_m})\]

The true task label \(y_m\) is available.

Inference routing\[(w_r,w_u,w_s)=h(x_1,x_2)\]

The router must predict interaction type from inputs only.

Fusion equation

Per-example mixture\[z(x)=w_r(x)z_r(x)+w_u(x)z_u(x)+w_s(x)z_s(x),\qquad \hat p(y\mid x)=\operatorname{softmax}(z(x))\]

Why routing may be easier than task prediction

The paper argues that “do these modalities agree, differ, or jointly shift meaning?” can depend on broader relation features than the final task label. A router can therefore be useful even when its base model would not solve the sarcasm or humor task perfectly.

But the router is the main observed bottleneck.

Oracle fusion is consistently much stronger than learned fusion in the ablation. The experts contain unrealized headroom; selecting them accurately is the difficult part.

Subtle question

If both unimodal models are weak and wrong, does \(\Delta=2\) prove true synergistic information?

No. It only assigns the paper’s proxy category. Both models may fail despite sufficient unimodal information. High-quality, calibrated unimodal labelers and confidence filtering reduce—but cannot eliminate—this ambiguity.

Failure modes

Text-side biasThe paper reports unimodal text models about 16 accuracy points above vision models in its analysis, skewing categories toward text uniqueness.
Proxy taxonomyPrediction disagreement is not an exact estimate of information-theoretic redundancy, uniqueness, or synergy.
Coarse granularityOne sample may contain several local interactions; a single R/U/S label compresses them into one bucket.
Router circularityThe system needs a capable multimodal model to infer which multimodal expert should solve the task.
Compute multiplicationDense soft fusion evaluates all expert copies and adds another fusion model.
Domain scopeEvidence centers on image/text or video/text affective tasks, not arbitrary sensors, medicine, or recommendation modalities.

When the idea is most plausible

Use MMoE when…

The task genuinely mixes congruent, one-sided, and relational cases; you have strong unimodal labelers; and the quality gain justifies multiple experts.

Prefer one model when…

Data is small, interaction regimes are not separable, latency is tight, or a single large backbone can already learn balanced cross-modal behavior.

Interview drill

Is this sparse MoE?

Not in the main method. It trains three full task experts and softly fuses their outputs; all may run at inference.

Why use the true label in categorization?

The category asks which modalities independently contain enough information for the correct task answer, so correctness must be measured against \(y_m\).

Why cannot \(\Delta\) be computed online?

It requires \(y_m\), the answer being predicted. A separate router estimates the interaction from inputs only.

Why soft fusion?

Interactions need not be pure, router uncertainty is real, and multiple experts may contain useful evidence.

Why is synergy hard?

The signal lies in a relation—often contradiction or complementarity—rather than either modality’s marginal features.

Closest limitation?

Expert quality is only useful if categorization and routing are accurate enough to expose it.

Self-test

1. Write the discrepancy and category equations.
2. Give one R, U, and S example.
3. Explain training versus inference routing.
4. Derive soft logit fusion.
5. Name two reasons a synergy label can be wrong.

1. \(\delta(a,b)=\mathbf 1[a\ne b]\), \(\Delta=\delta(y_1,y_m)+\delta(y_2,y_m)\), mapped 0/1/2 to R/U/S. 2. Any valid examples where both/one/neither unimodal prediction is correct. 3. Training uses the true label; inference uses a learned router from inputs. 4. \(z=\sum_e w_ez_e\), then the task link. 5. Weak or miscalibrated unimodal models, low confidence, distribution shift, label noise, or coarse sample-level categorization.
