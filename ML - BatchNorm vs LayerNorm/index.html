Normalization · the axis is the algorithm

BatchNorm compares columns. LayerNorm compares rows.

Both subtract a mean, divide by a standard deviation, then apply learned scale and shift. The decisive question is: which values are allowed to contribute to that mean and variance?

BatchNorm forms four groups—one vertical group per feature. Sample 1’s first value depends on samples 2 and 3’s first values.

BatchNorm on \(X\in\mathbb R^{B\times D}\) \[ \mu_j=\frac1B\sum_{b=1}^{B}x_{bj},\quad \sigma_j^2=\frac1B\sum_b(x_{bj}-\mu_j)^2 \]

Statistics indexed by feature \(j\); training examples are coupled.

LayerNorm on \(X\in\mathbb R^{B\times D}\) \[ \mu_b=\frac1D\sum_{j=1}^{D}x_{bj},\quad \sigma_b^2=\frac1D\sum_j(x_{bj}-\mu_b)^2 \]

Statistics indexed by example \(b\); examples remain independent.

Memory hook

BatchNorm asks, “Is this feature unusually high relative to its peers in the current batch?” LayerNorm asks, “Is this feature unusually high relative to the other features in this representation?”

Step 1 · Name every axis before writing a formula

“Normalize the activations” is incomplete until the reduction axes are explicit.

A tensor has sample, channel, token, spatial, and feature axes. Normalization selects reduction axes for statistics and parameter axes for \(\gamma,\beta\); those choices need not be identical across methods.

Axis map

Input shapeMethodStatistics reduce overTypical \(\gamma,\beta\) shape
[B,D]BatchNorm1d\(B\), separately for every \(D\)[D]
[B,D]LayerNorm(D)\(D\), separately for every \(B\)[D]
[B,C,H,W]BatchNorm2d\(B,H,W\), separately for every \(C\)[C]
[B,T,D]Transformer LayerNorm(D)\(D\), separately for every \((B,T)\)[D]
[B,C,H,W]LayerNorm([C,H,W])\(C,H,W\), separately for every \(B\)[C,H,W]

Reduction axes versus affine axes

BatchNorm2d

mean(x, axes=(B,H,W)) → [C]

One mean/variance and usually one learned scale/shift per channel.

Transformer LayerNorm

mean(x, axis=D) → [B,T,1]

One mean/variance per token vector; learned scale/shift shared over batch and token positions.

“Layer” is not a universal axis name.

A LayerNorm API normalizes the final dimensions listed by normalized_shape. In a Transformer that is usually only \(D\); in another architecture it can be several trailing dimensions.

Count the statistical groups

BatchNorm on \([B,D]\)\[\text{number of groups}=D,\qquad \text{values/group}=B\]
LayerNorm(D) on \([B,T,D]\)\[\text{number of groups}=BT,\qquad \text{values/group}=D\]
Step 2 · Understand BatchNorm

BatchNorm makes each feature coordinate relative to a batch population.

During training, the current mini-batch supplies statistics. Learned \(\gamma_j,\beta_j\) then let the model restore or change the normalized coordinate’s useful scale and location.

For feature \(j\) in a vector batch

1
\[\mu_j^{(B)}=\frac1B\sum_{b=1}^{B}x_{bj}\]
Batch mean.Collect the same feature from every example in the mini-batch.
2
\[(\sigma_j^2)^{(B)}=\frac1B\sum_b(x_{bj}-\mu_j^{(B)})^2\]
Batch variance.The forward normalization commonly uses the population-form denominator \(B\); library running-variance details can differ.
3
\[y_{bj}=\gamma_j\frac{x_{bj}-\mu_j^{(B)}}{\sqrt{(\sigma_j^2)^{(B)}+\epsilon}}+\beta_j\]
Standardize, then learn an affine map.After \(\gamma,\beta\), the output is not required to retain mean zero or variance one.

Why batch composition matters

Coupling

A sample’s training output changes if its batch companions change, even when the sample itself is identical.

Noise

Mini-batch statistics add stochasticity. It can regularize, but very small or non-IID batches can make estimates unreliable.

Synchronization

Distributed training may compute local-device statistics or synchronize them across devices, changing group size and communication.

What BatchNorm may help

The original paper motivated BatchNorm through “internal covariate shift.” Later empirical work challenged that as the main explanation and found evidence for smoother, more predictable optimization. The safest statement is practical: BatchNorm often permits stable, faster optimization in architectures and batch regimes where its statistics are reliable.

Step 3 · Understand LayerNorm

LayerNorm standardizes each representation without consulting another example.

For a Transformer token, all \(D\) channels of that token form one normalization group. Batch size, sequence position, and other users do not enter its statistics.

For one representation \(x_b\in\mathbb R^D\)

1
\[\mu_b=\frac1D\sum_{j=1}^{D}x_{bj}\]
Within-example mean.One example—or one token vector—supplies all values.
2
\[\sigma_b^2=\frac1D\sum_j(x_{bj}-\mu_b)^2\]
Within-example variance.There are no running statistics and no estimate from neighboring examples.
3
\[y_{bj}=\gamma_j\frac{x_{bj}-\mu_b}{\sqrt{\sigma_b^2+\epsilon}}+\beta_j\]
Shared learned coordinates.Statistics differ by example/token, while \(\gamma_j,\beta_j\) are shared model parameters.

Why sequence models like it

Batch-size independence

Training with batch one or serving one token/user does not require a different source of statistics.

Variable sequence lengths

Each token vector is normalized locally, so padding and length do not change another token’s LayerNorm statistics.

Same train/eval computation

No running mean/variance must be accumulated, serialized, or frozen.

Residual-stream scale control

Placed around attention and MLP sublayers, LayerNorm helps keep their inputs or outputs in a manageable range.

Invariances before \(\gamma,\beta\)

Shift every feature equally\[\operatorname{LN}(x+c\mathbf 1)=\operatorname{LN}(x)\]

The per-example mean absorbs the shift.

Positive uniform rescaling\[\operatorname{LN}(ax)\approx\operatorname{LN}(x),\quad a>0\]

Ignoring \(\epsilon\), scale cancels between numerator and denominator.

Normalization is not the final output constraint.

The standardized vector has mean zero and variance one; the learned affine output generally does not. \(\gamma,\beta\) preserve the layer’s ability to choose useful scales and offsets.

Deployment behavior · mode matters for BatchNorm

BatchNorm changes its source of statistics at evaluation; LayerNorm does not.

BatchNorm training

Normalize with the current mini-batch’s mean and variance. Also update running estimates stored in the module.

→
BatchNorm evaluation

Normalize with frozen running estimates, so one prediction does not depend on whichever examples happen to be served beside it.

LayerNorm training

Compute mean and variance from the current example/token’s normalized dimensions.

=
LayerNorm evaluation

Use the same per-example/token calculation. There is no running-statistics state.

A sample can change under BatchNorm training

Batch A\[x=3\text{ inside }[1,3,5]\Rightarrow \widehat x=0\]
Batch B\[x=3\text{ inside }[3,3,9]\Rightarrow \widehat x\approx-0.7071\]

The identical scalar \(x=3\) changes because its peers change. LayerNorm for the same representation would ignore other examples entirely.

Running-statistics pitfalls

Domain shiftFrozen training statistics may poorly represent a changed evaluation distribution.
Fine-tuning modeAccidentally updating or freezing BatchNorm statistics can materially change behavior.
Small batchesNoisy current statistics and slowly adapted running estimates can both be problematic.
Library detailsMomentum conventions and biased/unbiased variance handling differ; read the exact framework documentation.
Architecture shapes · CNNs and Transformers

The common use cases follow directly from which axes are stable.

Convolutional activations \([B,C,H,W]\)

BatchNorm2d

stats over (B,H,W), one group per C

Even with small \(B\), each channel may have \(BHW\) values. It also respects the idea that one convolutional channel means the same thing across spatial positions.

LayerNorm

stats over normalized_shape

LayerNorm([C,H,W]) normalizes an entire sample and learns elementwise affine parameters; channel-last LayerNorm(C) is a different operation.

Transformer activations \([B,T,D]\)

\[ \mu_{b,t}=\frac1D\sum_{j=1}^{D}x_{b,t,j},\qquad \sigma_{b,t}^2=\frac1D\sum_j(x_{b,t,j}-\mu_{b,t})^2. \]

Transformer LayerNorm(D) creates \(BT\) independent statistical groups. Token \((b,t)\) does not use a different token’s channels, so variable lengths and autoregressive serving do not create a train/eval statistics mismatch.

Why naïve BatchNorm is awkward for tokens

Variable lengths

Pooling over token positions requires careful masking or allows padding to corrupt statistics.

Autoregressive serving

Inference may process one new token, unlike the token populations seen during training.

Cross-example coupling

One sequence’s representation depends on other sequences assigned to the same mini-batch/device.

Small-batch nuance

Batch size one does not always mean one statistic value. BatchNorm2d still has \(H\times W\) positions per channel. A vector BatchNorm with shape \([1,D]\), however, has only one value per feature and cannot estimate useful training variance from that batch.
Residual networks · normalization location

Choosing LayerNorm does not yet specify where it sits in a Transformer block.

Pre-LN and Post-LN use the same normalization formula but expose different residual and gradient paths.

Post-LN\[y=\operatorname{LN}(x+F(x))\]

The original Transformer normalized after each residual addition.

Pre-LN\[y=x+F(\operatorname{LN}(x))\]

The residual path contains an explicit identity route around the normalized sublayer.

Do not collapse three questions

Which method?

BatchNorm, LayerNorm, RMSNorm, GroupNorm, or another normalization family.

Which axes?

The dimensions supplying statistics and the dimensions carrying learned affine parameters.

Where in the graph?

Before or after a linear/activation/sublayer and before or after residual addition.

A practical decision sequence

1 · Write the tensor shapeName B, C, T, H, W, D.

If the axes are vague, the normalization choice is not yet defined.

2 · Choose statistical peersShould examples influence one another?

For stable image batches, often yes; for independent token serving, usually no.

3 · Inspect deploymentWill evaluation batch composition match training?

If not, running statistics and mode management become central.

4 · Benchmark the architectureOptimization is empirical.

Compare converged quality, stability, throughput, and sensitivity—not only one training-loss snapshot.

Nearby alternatives

GroupNorm

Normalizes groups of channels per example; common when CNN batches are too small for reliable BatchNorm.

InstanceNorm

Normalizes each channel per example across spatial dimensions; useful when instance-level contrast/style matters.

RMSNorm

Rescales by root mean square without subtracting the mean; widely used as a simpler LayerNorm-relative in modern sequence models.

Axis check

For a Transformer tensor \([B,T,D]\), how many separate mean/variance pairs does LayerNorm(D) compute?

It computes \(B\times T\) pairs—one mean and variance for every token vector—each using its \(D\) feature values.

Accuracy and scope notes

Variance convention

The worked example uses the population-form denominator equal to group size and sets \(\epsilon=0\). Libraries add \(\epsilon\) and may treat running variance differently.

Optimization mechanism

The guide presents the original motivation and later challenge without claiming one settled causal explanation for BatchNorm’s success.

Architecture recommendations

“CNN” and “Transformer” are common patterns, not laws. Batch regime, layout, residual design, and implementation determine results.

Numerical values

The \(3\times4\) matrix and affine parameters were selected for transparent hand calculation, not copied from a trained network.
